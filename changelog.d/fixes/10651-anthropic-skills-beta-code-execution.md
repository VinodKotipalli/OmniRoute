- **fix(providers):** the `anthropic` API-key provider no longer sends `skills-2025-10-02` in its static `Anthropic-Beta` header. Anthropic rejects every request that carries that beta without a `code_execution` tool — `400 "Skills beta requires the code_execution tool to be included in the request"`, on Haiku, Sonnet and Opus alike — so after #9064 every plain API-key request (Claude Code, Agent SDK, raw curl) that declared no code_execution tool failed. The beta is now forwarded only when the client negotiated it (`FORWARDABLE_CLIENT_BETAS`, unchanged) or appended per request when the outgoing body declares a code_execution tool, which is the raw-curl `container.skills` case #9064 fixed; `code-execution-2025-08-25` alone is accepted upstream and stays static ([#10651](https://github.com/diegosouzapw/OmniRoute/pull/10651)) — thanks @dpozimski
